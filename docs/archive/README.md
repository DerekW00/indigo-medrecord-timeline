Use the [application README](../../build_claude/README.md), [demo commands](../../build_claude/DEMO.md), and [verification evidence](../../build_claude/DEMO_EVIDENCE.md) for the delivered application. The [adopted gold](../../eval/gold/record_1.json) is the only canonical label file.

Original file contents are retained, including earlier decisions that were superseded during integration. The root AGENTS.md and CLAUDE.md retain the initial build contract; the current application README records final decisions and known limitations.
