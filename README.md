# Medical Record Timeline

The runnable application is in [`build_claude/`](build_claude/README.md). It reviews scanned PDF bundles as a combined chronological timeline with source pages, persistent reviewer edits, retry, and duplicate grouping.

Start with the [application README](build_claude/README.md). The [demo evidence](build_claude/DEMO_EVIDENCE.md) records tested commits, acceptance results, limitations, and reproduction commands. Runtime files and medical material are excluded from Git.

This release is prepared on `consolidate/demo` for coordinator review. It is not deployed or merged to `main`.
